# Python Paper Trading Engine

A self-contained paper trading simulator built with Python, SQLite, and Yahoo Finance data.

## Features
- Real-time stock quotes via `yfinance`
- Account persistence using SQLite
- Risk management & order execution engine (Market, Limit, Stop Loss)
- Quantitative portfolio analytics (Sharpe ratio, drawdown, return metrics)
- Terminal UI dashboard

## How to Run
```bash
pip install -r requirements.txt
python trading_system.py
